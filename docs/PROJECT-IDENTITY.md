## Scope separation

The official website and this toolkit reference each other, but their publication scopes remain separate:

- `healthrenewal.org` is the canonical institutional domain and publishes the Rawafid platform plus the official open-source project pages.
- this repository publishes only general-purpose Arabic/RTL, i18n, accessibility, Unicode/bidi, testing, and generic UI engineering assets that are safe to distribute under Apache-2.0.

See `OPEN_SOURCE_SCOPE.md` for the enforceable repository boundary.
