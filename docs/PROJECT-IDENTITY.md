# Project identity

This file is the canonical identity reference for this open-source repository.

## Rawafid

- **Arabic name:** روافد
- **English/transliterated name:** Rawafid
- **Official production website:** https://healthrenewal.org/
- **Website role:** the official public website for the Rawafid platform.

The domain name is intentionally not the product name. `healthrenewal.org` is the canonical domain; the public-facing platform name is **Rawafid (روافد)**.

## Open-source toolkit

- **Project name:** Rawafid Arabic/RTL Accessibility & Localization Toolkit
- **Source repository:** https://github.com/khaledaltheeb/rawafid-arabic-rtl-a11y-toolkit
- **npm package:** `@rawafid/arabic-rtl-a11y-toolkit`
- **License:** Apache-2.0

This repository is a reusable engineering project associated with Rawafid. It is not a mirror of the production website and it does not contain Rawafid's scientific, health, psychological, encyclopedia, editorial, user, or proprietary production content.

## Canonical-link policy

Use these references consistently:

- When a form, profile, package registry, or partner asks for the **official website**, use `https://healthrenewal.org/`.
- When it asks for the **project/source code**, use this GitHub repository.
- When it asks for the **project name**, use `Rawafid Arabic/RTL Accessibility & Localization Toolkit`.
- When it asks for the **organization/platform name**, use `Rawafid` / `روافد`.
- When it asks for the **npm package**, use `@rawafid/arabic-rtl-a11y-toolkit` after publication.

Do not rename Rawafid to "Health Renewal" merely because of the domain. Do not describe the GitHub repository as the Rawafid production website.

## Scope separation

The official website and this toolkit may reference each other, but their publication scopes remain separate:

- `healthrenewal.org` publishes the Rawafid platform and its public content/services.
- this repository publishes only general-purpose Arabic/RTL, i18n, accessibility, Unicode/bidi, testing, and generic UI engineering assets that are safe to distribute under Apache-2.0.

See `OPEN_SOURCE_SCOPE.md` for the enforceable repository boundary.
