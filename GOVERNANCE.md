# Governance

The project is maintained as a non-commercial open-source engineering utility focused on Arabic/RTL, localization, accessibility, Unicode, and direction-aware UI behavior.

## Decision principles

Changes are evaluated against:

1. standards correctness;
2. accessibility and internationalization impact;
3. interoperability across browsers/runtimes;
4. security and supply-chain risk;
5. test evidence;
6. API simplicity and maintenance cost;
7. usefulness outside any one website;
8. strict adherence to the public-scope boundary.

## Maintainer responsibilities

Maintainers are responsible for reviewing scope/provenance, dependency licenses, security-sensitive changes, accessibility regressions, RTL/LTR parity, release integrity, and public API evolution.

## Review ownership

CODEOWNERS protects source, styles, workflows, security policy, and public-scope policy. As the maintainer community grows, ownership should be distributed so no single person becomes the only reviewer for all critical paths.

## Commercial separation

The toolkit itself is maintained as an open-source public good and is technically/editorially separate from Rawafid's scientific/content repositories. Apache-2.0 permits downstream commercial and non-commercial reuse; that license permission does not create a paid tier or commercial service for this toolkit.

Provider-specific OSS program requirements are evaluated honestly and independently. The project must not misrepresent eligibility to obtain benefits.
